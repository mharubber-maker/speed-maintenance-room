# غرفة صيانة سبيد

برنامج إدارة أوامر الصيانة لغرفة صيانة سبيد.

## ماذا يفعل البرنامج؟

- تسجيل أوامر الصيانة (الجهاز، السيريال، العطل، الإجراء، المهندس، العميل)
- بحث وتصفية حسب الشهر / المهندس / الحالة
- مسح باركود السيريال بالكاميرا
- إرسال رسالة واتساب للعميل عند التسليم
- تصدير واستيراد البيانات (CSV / JSON)
- البيانات محفوظة محلياً في المتصفح

## المهندسون

حازم · حامد · محمد · تيتو

## التشغيل على جهازك

تحتاج [Node.js 22](https://nodejs.org/) أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح المتصفح على العنوان الذي يظهر (عادة `http://localhost:8080`).

لبناء نسخة إنتاج:

```bash
npm run build
```

## محتويات المجلد

| المجلد | المحتوى |
|---|---|
| `src/` | كود التطبيق |
| `src/components/` | الواجهة (لوحة الأوامر، النموذج، الواتساب، الماسح) |
| `src/lib/` | المنطق والتخزين والتصدير |
| `src/data/` | بيانات البداية |
| `public/` | الأيقونات والملفات العامة |
| `attachments/` | ملف الإكسل الأصلي الذي بُني عليه البرنامج |

## ملاحظات

- لا يحتاج حساب أو سيرفر قاعدة بيانات للتشغيل اليومي: البيانات تُحفظ في المتصفح.
- اعمل نسخة تصدير (JSON أو CSV) بشكل دوري حتى لا تضيع البيانات إذا مُسحت ذاكرة المتصفح.
